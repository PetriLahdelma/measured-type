# Code of Conduct

Measured Type adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the issues, pull requests and discussions of this repository
and anywhere someone represents the project.

In short:

- Be kind and assume good intent. Critique work, measurements and sources,
  not people.
- Disagreement about typography is welcome; back it with a source or a
  measurement.
- No harassment, insults, personal attacks or sexualised language or
  imagery, and no publishing anyone's private information.

## Reporting

Report behaviour that breaks this code privately to the maintainer, Petri
Lahdelma, through the contact details at
[digitaltableteur.com](https://digitaltableteur.com) or on the
[GitHub profile](https://github.com/PetriLahdelma). Reports are read in
confidence. The maintainer may remove comments, close threads or block
accounts that break this code, following the enforcement guidelines of the
Contributor Covenant.
