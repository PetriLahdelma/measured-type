Write article.css for long-form case studies on our site. The markup is `<article class="prose" lang="en">` with p, h2, h3, em, abbr (acronyms such as WCAG, SAP and API, sometimes inside an em passage), a small results table of numbers and an uppercase eyebrow label `.eyebrow`. Body text is Source Serif 4, self-hosted: fonts/SourceSerif4[opsz,wght].ttf with fonts/SourceSerif4-Italic[opsz,wght].ttf beside it. Headings, the eyebrow and the results table use Outfit: fonts/Outfit[wght].ttf. Read the font files, do not modify them. Use the fonts' OpenType features where they genuinely help. Save article.css and a short notes.md explaining the font decisions.

Input files: fonts/SourceSerif4[opsz,wght].ttf, fonts/SourceSerif4-Italic[opsz,wght].ttf, fonts/Outfit[wght].ttf
