# Moved

The skill was renamed `measured-typography` on 10 November 2026 and lives in
[`skills/measured-typography/`](../measured-typography/). The repository, the
brand (Measured Type) and the marketplace keep their names.

Install it as `measured-typography`:

```bash
npx skills add PetriLahdelma/measured-type --skill measured-typography --agent claude-code -g
```

or, in Claude Code, `/plugin install measured-typography@measured-type`. If you
installed the plugin as `measured-type`, Claude Code renames it in your
settings; run that install line once to fetch it under the new name. See
[spec 0033](../../specs/0033-rename-to-measured-typography.md).
